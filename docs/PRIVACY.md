# Privacy

This first version is a static public website. It has no application server, analytics, advertising, tracking cookies, accounts, subscriber database or bill-upload endpoint. Assets and the reviewed public dataset are served from the same site. A hosting provider may retain ordinary access logs under its own policy.

## Comment drafts

The name, city and personal experience fields are optional. Values are used in the current tab to prepare an editable draft. They are not written to local storage, sent to an AI model, transmitted to this project’s server, or committed to GitHub. Refreshing or closing the page clears the draft. Downloading a draft creates a file on the visitor’s device; copying it uses the device clipboard.

The CPUC’s own website handles public submission. Its comments become public. This project does not automatically submit comments, sign petitions, or send messages on the visitor’s behalf. Review personal information before posting.

## Other services

Links to TURN, CPUC subscriptions and GitHub open external services with their own policies. GitHub issues and pull requests are public. Do not submit private contact details, account numbers, bills, or sensitive personal stories in an issue.

The initial dataset includes only aggregate, dated comment counts. It does not include a contact list or individual commenter profiles.

## Future organizing integrations

An optional external opt-in form can be configured, but no project-owned signup service is connected initially. Before collecting contacts, establish an identified list owner, collection purpose, explicit opt-in, unsubscribe and deletion paths, access controls, retention policy and an updated public notice. Do not infer consent from a CPUC comment, petition signature elsewhere, GitHub activity or membership in another organization.

Do not store subscriber exports or uploaded bills in this public repository. Use an appropriate restricted service for any future sensitive records. Publish aggregate organizing metrics only when there is actual data and a clear methodology.
