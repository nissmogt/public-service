# Implementation roadmap

## Available in the first release

- [x] Static, mobile-friendly SoCalGas dashboard and related SDG&E docket link.
- [x] Source-backed financial chart, composition table and source dialogs.
- [x] Searchable evidence records with unresolved questions labeled.
- [x] Accountability tracker with unlogged responses made explicit.
- [x] Browser-local comment drafting and copy/download controls.
- [x] Pacific-time hearing calendars and historical-event handling.
- [x] Aggregate comment snapshots, review dates and stale-record warning.
- [x] Existing organizing links and configurable external signup link.
- [x] Repository contribution forms, data validation, tests and manual Pages publication workflow.

## Next: a working organizing relationship

- Identify a small organizing team and contact TURN about useful collaboration. No affiliation or endorsement is implied by this repository.
- Agree on shared demands and a review owner for each research question.
- Connect an organizer-owned, voluntary signup form; define consent, unsubscribe, retention and deletion before collecting contacts.
- Coordinate hearing preparation and publish genuine participation metrics. Do not present targets as achievements.

## Next: document review and ingestion

- Add a reviewed inventory of related applications and their combined customer effects.
- Add a comparable category-by-category reconciliation of the increase; the current composition chart is not that reconciliation.
- Record major capital alternatives, procurement documents, contractors and actual payments, with carefully scoped findings.
- Implement document ingestion with URL/date/hash manifests, page-aware extraction, candidate claims and human-reviewed pull requests. Read `METHODOLOGY.md` before adding AI support.
- Add a manual aggregate snapshot importer before considering any scheduled docket collection. Preserve source dates and never auto-update review dates just because a job ran.

## Later: additional utilities

- A full SDG&E case with its own sourced figures and customer impact assumptions.
- Glendale water and electricity with their own city decisions, financial baselines and hearing processes.
- Multi-case navigation only after validating case-aware rendering and accountability records. The current UI deliberately presents one researched case.

## Operational limits

There is no connected mailing list, automatic document monitor, live comment feed, AI research service or deployed backend in this release. Public issue forms are for research and code, not private organizing records. GitHub Pages must be enabled in repository settings before the publication workflow can deploy.
